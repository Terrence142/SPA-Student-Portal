## Professional Summary
The SPA-Student-Portal is a modern, responsive web application built with Next.js and React, designed to streamline student administrative tasks and information management. This project demonstrates proficiency in building full-stack web applications, integrating modern frontend frameworks with robust backend services like Supabase.

## 🛠️ Core Competencies Demonstrated
*   **Full-Stack Development**: Integrating Next.js frontend with Supabase backend.
*   **Modern UI/UX**: Utilizing Tailwind CSS and Lucide React for a clean, professional interface.
*   **State Management & Data Fetching**: Implementing efficient data handling with SWR.
*   **Type Safety**: Leveraging TypeScript for robust and maintainable code.
*   **Performance & PWA**: Leveraging Next.js 16 and Serwist for optimized application performance and PWA capabilities.

## 📂 Project Structure & Features
*   **Next.js Framework**: Utilizing modern App Router for efficient routing and performance.
*   **Secure Authentication**: Leveraging Supabase for user session management.
*   **Modern Styling**: Responsive design using Tailwind CSS.
*   **Interactive UI**: Enhanced user feedback using SweetAlert2.

## 🚀 Getting Started
1. **Clone the repository**:
   ```bash
   git clone https://github.com/MarkAngelGuevarra/SPA-Student-Portal.git
   ```
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Configure Environment Variables**: Ensure your Supabase credentials are correctly set up.
4. **Run the development server**:
   ```bash
   npm run dev
   ```
